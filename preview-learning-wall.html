Golang Backend Performance

Materi goroutine pool kemarin langsung kita coba terapkan di service sync database internal. Ternyata alokasi memory turun hampir 40% cuma dengan membatasi worker concurrency secara terukur, bukan spawn goroutine liar di setiap HTTP request.

Tips Praktis yang Bisa Dicoba Rekan Tim: Selalu gunakan buffered channel worker pattern saat mengolah batch query di atas 10.000 rows agar heap memory stabil.

E2E Testing Playwright

Insight terbesar dari sesi ini adalah fitur tracing & auto-waiting Playwright. Kita tidak butuh lagi `sleep()` atau `waitForTimeout()` manual yang bikin test flacky. Script test yang tadinya sering gagal sendiri di CI/CD sekarang 100% konsisten hijau.

Tips Praktis yang Bisa Dicoba Rekan Tim: Gunakan mode `trace: 'on-first-retry'` di file konfigurasi Playwright supaya bisa memutar video rekaman klik persis saat ada test yang fail.

Pemodelan Cashflow Excel

Ternyata kombinasi fungsi `XLOOKUP` dengan dynamic array `LAMBDA` bisa memangkas rumus panjang bertingkat yang rawan error saat rekapitulasi budget bulanan. Template audit yang tadinya butuh 3 jam, sekarang selesai di bawah 30 menit.

Tips Praktis yang Bisa Dicoba Rekan Tim: Hindari hardcode range pada formula Excel, ubah seluruh data transaksi menjadi format Tabel resmi (`Ctrl + T`) agar rumus ekspansi otomatis.

Komunikasi Empatik Klien

Kunci utama saat menghadapi klien yang sedang marah bukan langsung memberi bantahan teknis, melainkan melakukan validasi emosi dulu selama 60 detik pertama ("Saya paham situasi ini menghambat operasional bapak..."). Begitu tensi turun, baru tawarkan 2 opsi solusi konkret.

Tips Praktis yang Bisa Dicoba Rekan Tim: Gunakan teknik LASR: Listen (dengar tanpa potong) → Acknowledge (akui dampak masalahnya) → Solve (berikan tindakan) → Reassure (beri estimasi waktu update).
